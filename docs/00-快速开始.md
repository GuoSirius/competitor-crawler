# 00 · 快速开始（新设备拉取与运行）

> 本文是**首次在新机器上拉取并跑起本项目**的最小步骤清单。详细设计见 `docs/` 各篇（索引在 `docs/README.md`）。

## 环境要求

| 项 | 版本 / 要求 | 备注 |
|---|---|---|
| Node.js | **>= 24** | `corepack` 自动按 `.nvmrc` 取 24 |
| pnpm | **12.x** | `corepack enable && corepack prepare pnpm@12 --activate` |
| Git | 任意较新版本 | 用于 clone |
| 系统 | Windows / macOS / Linux | 原生模块 `better-sqlite3` 需本地编译工具链（Windows 需 VS 构建工具） |

## 首次安装（新设备四步）

```bash
# 0. 拉取仓库
git clone https://github.com/GuoSirius/competitor-crawler.git
cd competitor-crawler

# 1. 安装依赖（monorepo 根目录一次装全）
pnpm install

# 2. 安装 Playwright 浏览器内核（用封装好的 pnpm playwright:install，避免 root 下找不到二进制）
pnpm playwright:install

# 3. 准备环境变量
cp .env.example .env
#   按需编辑 .env：DB_DIALECT=sqlite，MODEL_MODE=hybrid（详见 .env.example 注释）

# 4. 初始化数据库表结构（Drizzle push，本地 SQLite 默认无需额外服务）
pnpm --filter @competitor-crawler/shared db:push
```

## 常用命令（根 package.json scripts）

| 命令 | 作用 |
|---|---|
| `pnpm seed` | 读取 `data/seeds/*.xlsx` → 增量同步公司 / 品类进库 |
| `pnpm crawl` | 跑全量增量爬取（按 seeds + 站点适配器） |
| `pnpm report` | 生成下游交付物（导出 / 图表 / 应用页） |
| `pnpm typecheck` | 类型检查（shared + crawler + web；web 未装 `vue-tsc` 时自动跳过，见 docs/12 §12.9） |
| `pnpm probe --domain <d> --list-url <u>` | 单站验证：抽测 YAML 解析是否正确（多规则站点加 `--section <key>`） |
| `pnpm gen-site --domain <d> --list-url <u>` | 模型驱动生成站点 YAML 配置 |
| `pnpm backfill --column <c> --row-key <k>` | 把 row 中字段晋升回填到新列 |
| `pnpm db:push` | 重建 / 同步表结构（改 schema 后跑，唯一迁移入口） |
| `pnpm release` | 版本 bump（运行时选/传 patch / minor / major）+ 生成 CHANGELOG + 打 `vX.Y.Z` 标签 |

> 完整脚本清单与用法见 [`11-脚本命令手册.md`](11-脚本命令手册.md)（单一真相源，后续新增脚本统一在此登记）。

## 注意事项（一次到位，避免重复踩坑）

- **pnpm 12 构建白名单已配好**：`pnpm-workspace.yaml` 用 `allowBuilds`（better-sqlite3 / esbuild / playwright），clone 后即生效，无需再改。若误用旧字段 `onlyBuiltDependencies` 会报 `ERR_PNPM_IGNORED_BUILDS`。
- **跑 monorepo 内 CLI 用 `pnpm exec`，绝不用 `npx`**：`npx` 走 npm、不认 pnpm 专属 `.npmrc`，且依赖未装时会找不到包。
- **国外站点不可达**：系统会主动告警，开 VPN 后 `pnpm crawl --site <domain>` 单站补跑，不阻塞其他站（见 `docs/06`）。
- **模型辅助**：默认 `hybrid`（本地 Ollama 为主 + 云端兜底）。本地模型需先 `ollama pull qwen2.5:14b-instruct` 等（见 `docs/04`）。

## 故障自查

| 现象 | 原因 / 处理 |
|---|---|
| `ERR_PNPM_IGNORED_BUILDS: better-sqlite3/esbuild` | pnpm 12 白名单字段写错 → 确认 `pnpm-workspace.yaml` 顶层为 `allowBuilds`，非 `onlyBuiltDependencies` |
| `playwright: command not found`（用 npx 时） | 改用 `pnpm playwright:install` |
| 装完跑 `pnpm seed` 报缺表 | 漏了第 4 步 `db:push` |
