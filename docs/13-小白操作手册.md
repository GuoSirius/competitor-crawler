# 13 · 小白操作手册（非开发同学专用）

> 面向市场部 / 产品部等**非技术同事**的完整上手手册。
> 目标：照着一步步复制粘贴命令，就能完成「装环境 → 初始化 → 跑爬取 → 出报告 → 加新站点」全流程。
> 原理与架构不用懂，想知道「为什么」再看 [02-架构设计](02-架构设计.md)；想查全部命令细节看 [11-脚本命令手册](11-脚本命令手册.md)。

## 0. 这个项目是干什么的（30 秒版）

自动抓取 **59 家竞品公司**官网上的产品信息（名称 / 货号 / 规格 / 价格），存进一个本地数据库，
然后一键导出成 Excel 报告（含图表），供比价和市场分析使用。

你日常只需要记住 3 个命令：

| 想做什么 | 命令 |
|---|---|
| 抓数据 | `pnpm crawl` |
| 出报告 | `pnpm report` |
| 只想试跑看看（不写库） | `pnpm crawl -- --dry-run` |

## 1. 第一次准备（每台电脑只做一次）

### 1.1 安装 3 个基础软件

按顺序装，每个装完重启一次终端（黑窗口）再装下一个：

| 软件 | 怎么装 | 怎么确认装好了 |
|---|---|---|
| **Git**（拉代码用） | 官网 https://git-scm.com/download/win 一路下一步 | 终端输入 `git --version` 有版本号 |
| **Node.js 24** | 官网 https://nodejs.org/ 下载 24.x LTS 安装包 | `node -v` 显示 v24.x |
| **pnpm 12.5.1** | 终端输入 `npm install -g pnpm@12.5.1` | `pnpm -v` 显示 12.5.1 |

> 💡 「终端」就是 Windows 的命令行：按 `Win` 键 → 输入 `cmd` 或 `PowerShell` → 回车。
> 💡 如果公司有代理/VPN 要求，先连上 VPN 再执行后面所有联网步骤。

### 1.2 把代码拉下来

```bash
cd /d/你的工作目录        # 选个你找得到的地方，比如 D:/workspace
git clone https://github.com/GuoSirius/competitor-crawler.git
cd competitor-crawler
```

> 没有权限？先在 GitHub 网页上用公司账号注册/登录，让系统开发组把你加进仓库。

### 1.3 安装项目依赖

```bash
pnpm install
```

第一次跑会下载几分钟，出现 `Done` 即成功。**这一步只需要做一次**；以后别人加了新功能你 `git pull` 后再跑一次即可。

### 1.4 配置 `.env`（项目钥匙串）

```bash
copy .env.example .env     # Windows；Mac/Linux 用 cp .env.example .env
```

然后用记事本打开 `.env`，按需修改：

| 配置项 | 填什么 | 不填会怎样 |
|---|---|---|
| `DATABASE_URL` | **默认别动**（`./data/crawler.sqlite` 本地数据库文件） | — |
| `MODEL_CLOUD_API_KEY` | 模型服务的 key（找系统开发组要） | 只影响「复杂站点自动兜底」，常规爬取不受影响 |
| 其他 `MODEL_*` | 默认别动 | — |

### 1.5 初始化数据库（建表 + 导入 59 家竞品名单）

```bash
pnpm db:push    # 建表（第一次必须跑）
pnpm seed       # 导入种子：59 家公司 + 109 个品类（重复跑安全，不会重复插入）
```

看到「59」「109」字样即成功。数据库文件在 `data/crawler.sqlite`（Excel 里的名单就是从这里来的）。

## 2. 日常操作（每天可能用到的）

### 2.1 抓数据

```bash
pnpm crawl                          # 全量：所有已配置站点
pnpm crawl -- --site www.liankebio.com          # 只抓某一站
pnpm crawl -- --site www.liankebio.com --section elisa-kit   # 只抓某站的某栏目
pnpm crawl -- --limit 5             # 每栏目只抓 5 条（快速验证用）
pnpm crawl -- --dry-run             # 演练模式：真实访问但不写库，用来「先看看会抓到啥」
```

> ⚠️ `pnpm crawl` 和 `--` 参数之间有空格加两横线，这是 pnpm 的语法，别漏。
> 抓取耗时取决于站点数量和网络，全量一般 10~60 分钟。中途断了就重跑，**重复抓不会产生重复数据**（自动去重）。

### 2.2 出报告（Excel）

```bash
pnpm report
```

产物在 **`data/exports/`** 目录：Excel 汇总表 + 图表。把这个目录里的文件直接发给需要的人即可。

### 2.3 更新代码（每周或听说有新功能时）

```bash
git pull
pnpm install        # 提示有变化时才需要
```

## 3. 新增 / 修改一个竞品站点（进阶）

**大部分情况下不需要你做**——把站点网址和产品页链接发给系统开发组即可。
如果你想自己动手，有两条路（字段详解见 [05-站点接入指南](05-站点接入指南.md)）：

### 路线一（推荐）：脚本 + 模型自动生成

```bash
# ① 让模型抓取该站列表页，自动生成初版 YAML（会自动识别列表/详情结构）
pnpm gen-site -- --domain 域名 --list-url "https://该站的产品列表页URL" --company-key "公司名"

# ② 验证：probe 自动判定规格×价格形态，解析不了会打印告警和建议
pnpm probe -- --domain 域名

# ③ 演练确认后正式抓
pnpm crawl -- --site 域名 --dry-run --limit 3     # 看到「解析 N 条、失败 0」即 OK
pnpm crawl -- --site 域名
```

模型生成**不保证 100% 准确**，② 的 probe/演练报错时，微调 YAML 里的选择器再验。

### 路线二：批量生成（一次要加很多站时）

```bash
pnpm gen-site:template        # 生成 Excel 模板 data/seeds/gen-site-template.xlsx
# ↑ 在 Excel 里按行填「域名/列表页/详情页/公司/是否需渲染」，保存
pnpm gen-site:batch           # 逐行批量生成，单行失败不影响其他行
```

### 路线三：手写模板（前两条都不奏效时）

复制 `config/sites/_template.yaml` → 改名 `config/sites/域名.yaml` → 照模板注释改选择器 → 同上 ②③。

> 无论哪条路：新站点**必须先 `--dry-run` 演练**再正式抓；多栏目的站用 `sections` 写法（参考 `config/sites/www.xpbiomed.com.yaml`）。
> 全部站点接入进度与遗留问题见 [14-站点接入问题清单](14-站点接入问题清单.md)。

## 4. 常见问题（FAQ）

| 现象 | 原因 | 解决 |
|---|---|---|
| `pnpm : 无法识别` | pnpm 没装好或终端没重启 | 重开终端再试；或重跑 `npm install -g pnpm@12.5.1` |
| `Cannot open database because the directory does not exist` | `data/` 目录不存在 | 手动新建 `data` 空文件夹后重跑 |
| 某站抓到 0 条 | 站点改版 / 选择器失效 / 被反爬 | 加 `--dry-run` 重试确认；仍为 0 就记录下来发开发组 |
| 某站报 403 / 「风险警告」 | 网站反爬拦截 | 记录站点名发开发组（有专门绕行方案，别自己重试轰炸） |
| 报告里价格是空的 | 该站价格由浏览器脚本动态生成，静态抓取拿不到 | 属正常现象，已记录在「待处理清单」，等开发组接入接口方案 |
| 抓到重复数据 | 不会。系统按「公司+产品页地址+栏目」自动去重 | 无需处理 |
| 想重抓某站最新价格 | 直接重跑该站命令 | 价格变化会记入历史表，不覆盖 |

## 5. 名词表（听同事说黑话时对照）

| 黑话 | 意思 |
|---|---|
| 种子（seeds） | 59 家竞品公司的名单（来自 Excel `data/seeds/*.xlsx`） |
| 品类（category） | 每家公司的产品大类，如「流式抗体」「胎牛血清」 |
| 栏目（section） | 一个站点里的一套抓取规则；一个站可有多个栏目 |
| dry-run / 演练 | 真访问网页但**不写数据库**，用来看「会抓到什么」 |
| 形态 A~E | 价格藏在页面里的 5 种花样（表格行/下拉框/内联JSON/异步接口/前端计算），probe 会自动识别 |
| WAF | 网站的「门卫」，拦截机器人访问，需要专门钥匙（cookie）通过 |
