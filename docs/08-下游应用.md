# 08 · 下游应用

> 本篇回答"**爬来的数据怎么变成市场/产品部能用得上的东西**"。数据落地后有三层交付：导出 → 图表 → 应用页。

## 8.1 业务视角：交付物给谁、解决什么

| 交付物 | 受众 | 典型用途 |
|---|---|---|
| Excel 导出 | 市场/产品部（汇报、二次加工） | 季度对标表、价格清单、品类覆盖 |
| 图表（ECharts） | 汇报 / 看板 | 各竞品产品数趋势、品类价格分布、克隆号覆盖饼图 |
| Nuxt 应用页 | 内部分析平台 | 可筛选、可下钻的竞品对标看板，长期沉淀 |

## 8.2 统一数据视图

下游一律从 DB 读，核心视图：

```sql
-- 活跃产品 + 公司 + 品类 三表 join
SELECT c.name AS company, cat.name AS category, p.name, p.clone_number,
       p.specs, p.applications, p.status, p.last_seen_at
FROM products p
JOIN companies c  ON c.id = p.company_id
JOIN categories cat ON cat.id = p.category_id
WHERE p.status = 'active';
```

- `specs` / `introMedia` / `row` 是 JSON 列，下游用 JSON 函数或应用层解析。
- 历史下架产品可通过 `status='delisted'` 放宽查询，做"下架前快照"分析。

## 8.3 Excel 导出（ExcelJS）

- 由 `pnpm report --excel` 触发，输出 `data/exports/<季度>-竞品对标.xlsx`。
- 工作表建议：
  1. **总览**：各公司 × 品类 产品数矩阵。
  2. **价格清单**：产品 + 规格 + 现价/活动价/优惠价（specs 展开为多行）。
  3. **字段覆盖**：各公司克隆号/应用 覆盖率，暴露数据缺口。
- 支持按公司/品类筛选后导出（`--company abcam --category "Primary Antibodies"`）。
- 复用你此前为 Flow Cytometry 页面构建 Excel 索引（title/pdfUrl/keywords）的经验。

## 8.4 图表（ECharts）

> ✅ **已实现**：`pnpm report --charts` 输出自包含 HTML（ECharts 走 CDN，含 6 张图）。
> ⚠️ 刻意**不消费 `price_history`**（该表只写不读，走势/涨跌告警属用户明确「后期再看」的范围）；
> 价格相关图一律基于**当前快照**（`products.specs` / `products.price`）。

`pnpm report --charts` 生成静态 HTML（可嵌内部 wiki）或喂给 Nuxt 看板：

| 图表 | 维度 | 业务问题 |
|---|---|---|
| 折线图 | 时间(季度) × 各公司产品总数 | 谁在快速扩张品类？ |
| 柱状图 | 公司 × 某品类产品数 | 该品类谁家最全？ |
| 饼图 | 某品类下各公司占比 | 市场集中度 |
| 价格分布直方图 | specs.priceNow（按区间分桶） | 定价带在哪？ |
| 堆叠柱状 | 公司 × (有克隆号/无克隆号) | 数据完整度对比 |

- 价格类图表注意：现价/活动价/优惠价三者并存时，明确用哪个口径（默认现价 `priceNow`，可切换）。
- `row` 字段异构：画图前先 `schema` 探测各站 row 共有键，取交集维度。

## 8.5 Nuxt 3 应用页

- `packages/web`（Nuxt 3 + Vue 3 + UnoCSS，贴合你既有技术栈与三态页头组件经验）。
- 页面能力：
  - **筛选器**：公司 / 品类 / 状态（活跃/下架）/ 是否有克隆号 / 价格区间。
  - **对标看板**：上方图表 + 下方可排序产品表（点开看 `row` 全量原始字段）。
  - **下钻**：公司 → 品类 → 产品 → 历史快照（last_seen_at / 历次 specs）。
  - **告警面板**：联动 `alerts` 表，展示待复核的规则问题。
- 数据来源：Nuxt server 直连 DB（或只读副本）；生产切 MySQL/PG 时连接串改 `.env` 即可（见 09）。

## 8.6 交付节奏

- **季度**：随爬取批次自动出 Excel + 图表，推送至工作群/邮件。
- **日常**：应用页常驻，随时可查最新快照。
- **临时**：指定公司/品类 ad-hoc 导出，支撑单次汇报。

## 8.7 与既有项目的能力复用

- 图表/看板可参考你 elabcn-nuxt 的 ISR + 组件化经验；
- 邮件 HTML 可复用 juice-email-cli（Mustache + CSS 内联）生成兼容性好的告警/周报邮件；
- 公共页头组件（三态页头）可直接用于应用页统一导航。
