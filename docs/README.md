## 约定

- 根 `README.md` 做总览 + 导航；细节按主题拆进本目录（避免单文件膨胀）。
- 重要技术决策记 `decisions/ADR-xxx.md`，含「背景 / 决策 / 理由 / 后果」，便于追溯。
- 架构图见 [assets/architecture.svg](assets/architecture.svg)。
- 文档与代码分离：配置（站点选择器、模型参数）放 `config/`，逻辑放代码包；改规则优先改配置、不动代码。
