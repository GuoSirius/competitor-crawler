# 02 · 架构设计

> 本篇回答"**我们怎么做**"的整体架构。逐层职责与交互见 [assets/architecture.svg](assets/architecture.svg)。

## 2.1 端到端流水线

```
Excel 超链接清单
   │  scripts/xlsx-to-seeds（抽取为「标准 JSON」）
   ▼
标准 seeds.json ──► ② Seed Loader（增量同步到 DB）
   │
   ▼  季度 Scheduler 触发
③ Fetch 层（Playwright 渲染优先 → 模型提取；接口逆向仅作稳定/无签名站点的可选优化）
   │
   ▼
④ Adapter Registry（按域名路由：配置 YAML / 代码 Adapter / 模型通用适配器）
   │   配置 YAML 支持单规则与 sections 多栏目多规则（一域名多套规则，见 05.3.2）
   │
   ▼
⑤ Normalizer（归一化为统一 NormalizedProduct）
   │
   ▼
⑥ Diff Engine（upsert / 软删 / 变化检测）
   │                         │
   ▼                         ▼
⑦ Storage(Drizzle:SQLite→MySQL/PG)   Alert Engine → 邮件/企微/钉钉
   │
   ▼
⑧ Downstream（Excel 导出 / ECharts / Nuxt 应用页）
```

**模型辅助层（贯穿 ③④⑤⑥）**：自适应提取、字段归一化、变化归因、告警摘要，统一经 OpenAI 兼容客户端调用，受严格提示词 + Zod 校验约束（见 04）。

## 2.2 分层职责

| 层 | 职责 | 关键产物 |
|---|---|---|
| 种子源 | Excel → 标准 JSON（一次性/周期性脚本） | `data/seeds/*.json` |
| Seed Loader | JSON 与 DB 做增量同步（增/改/删→软标记） | companies / categories 表 |
| Scheduler | 季度触发 crawl；也可手动单跑 | cron / node-cron |
| Fetch 层 | HTTP(undici) 抓页面；Playwright 抓包定位翻页/列表接口；限速/UA/代理 | 页面 HTML / JSON |
| Adapter Registry | 按域名路由到配置或代码解析器；配置支持单规则 / sections 多栏目多规则；模型通用适配器兜底 | 统一产品数据 |
| Normalizer | 异构字段 → 统一 `NormalizedProduct`；其余存 `raw_row` | 结构化产品 |
| Diff Engine | 比对上次快照：upsert / 软删 / 产出告警 | products / alerts / crawls |
| Storage | Drizzle ORM，SQLite 本地，生产切 MySQL/PG | 数据库 |
| Alert Engine | 分类分级告警，推送指定通道 | 告警事件 |
| Downstream | 导出 / 图表 / 应用页 | 给市场·产品部的交付物 |

## 2.3 设计原则

1. **配置优于代码**：简单站点改 `config/sites/*.yaml` 即可，不动代码；复杂站点才写 Adapter 类。
2. **单一事实源**：DB schema、类型、模型客户端只在 `packages/shared`，crawler 与 web 共用。
3. **边界归一化**：适配器输出统一结构，下游完全不感知站点差异（见 05）。
4. **无感切换**：DB 方言、模型本地/云端，仅靠环境变量切换（见 03 / 04）。
5. **失败可观测（human-in-the-loop）**：凡需人工介入的情况（国外站不可达、翻页接口定位不到）一律**主动告警**，不静默失败（见 07）。

## 2.4 技术选型（详见 ADR）

- 语言/运行时：Node.js + TypeScript（ESM）
- 抓取：Playwright（无头浏览器）+ undici/axios（HTTP）+ cheerio（SSR 解析）
- 模型：本地轻量模型（Ollama/vLLM，如 Qwen2.5-VL）+ 云端大模型兜底（通义 / DeepSeek / Claude），OpenAI 兼容接口
- 存储：Drizzle ORM（SQLite → MySQL / PostgreSQL）
- 下游：ExcelJS / ECharts / Nuxt 3
