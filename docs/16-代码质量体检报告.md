## 16.2 🔴 阻断项（合并前必须解决）

### 🔴-1 MySQL 方言唯一索引建在 TEXT 列、缺前缀长度
- **文件**：`packages/shared/src/db/schema-mysql.ts:67`（`uniq_product`）、`:129`（`uniq_content`）
- **事实**：`identityKey` / `sectionKey` 定义为 `text('...')`，却在 `uniqueIndex(...).on(companyId, identityKey, sectionKey)` 中直接建唯一索引，未指定前缀长度。
- **为何阻断**：MySQL 对 `TEXT` 列建索引必须指定前缀长度，否则 `db:push` 报 `ERROR 1170 (42000): BLOB/TEXT column used in key specification without a key length`。这直接破坏 `docs/09`「切 MySQL/PG 零改动、业务代码零改动」的契约——部署期必现。
- **修复**：把 `identityKey`/`sectionKey` 改为定长 `varchar(1024)`（推荐），或在 `uniqueIndex` 上用 `t.identityKey.substring(0, 255)` 指定前缀；并在 mysql 实例上 `db:push` 实测确认。

### 🔴-2 代码适配器层是空壳（加性契约未真正接线）
- **文件**：`packages/crawler/src/config/loader.ts:30`（`hasCodeAdapter`）、`packages/crawler/src/commands/crawl.ts:368,422`（仅把域名推进 `adapterSites` 数组并打印"钩子生效"）
- **事实**：全仓 **无任何 `import()` 动态加载适配器、无任何 `preflight/transformList/transformDetail/onHtml` 钩子调用点**（已 grep 核实）。`hasCodeAdapter` 只用于"统计并提示"，但钩子从未被调用。当前 `adapters/` 目录仅有 `.gitkeep`，故**暂无线上回归**。
- **为何阻断**：机制损坏且日志误导。一旦有人在 `adapters/<domain>.ts` 新建钩子，会被报告为"钩子生效"却实际零效果，静默违反「YAML → 代码 Adapter → 模型兜底」的加性契约。
- **修复**：二选一——(a) 落地 `import(\`./adapters/${domain}.js\`)` 并在解析管线中真正调用钩子；或 (b) 移除 `hasCodeAdapter` 伪实现与"钩子生效"文案，明确标注"代码适配器暂未启用"。

### 🔴-3 `schedule` 命令入口在 crawler 子包缺失 → `pnpm schedule` 必失败
- **文件**：`packages/crawler/package.json:6-16`（scripts 无 `schedule`）；根 `package.json:19`（`"schedule": "pnpm --filter @competitor-crawler/crawler schedule"`）
- **事实**：根脚本把 `schedule` 委派给 crawler 子包，但子包 scripts 只有 `seed/crawl/report/probe/gen-site*/backfill/typecheck`，**没有 `schedule`**。`cli.ts` 已实现 `schedule` 分支。
- **为何阻断**：`docs/11 §11.4` 明载 `schedule` 是可用命令（含 `--daemon`），但入口只登记在根、未在子包落地，命令实际不可用，与文档契约冲突。
- **修复**：在 `packages/crawler/package.json` 增加 `"schedule": "tsx src/cli.ts schedule"`（与 `seed`/`crawl` 同构）；并同步 `cli.ts` 帮助文案。

### 🔴-4 web 时间展示用裸 `new Date()` 且时区错误
- **文件**：`packages/web/pages/contents.vue:44`、`packages/web/pages/alerts.vue:64`
- **事实**：`contents.vue` 用 `new Date(ts * 1000).toLocaleDateString('zh-CN')`；`alerts.vue` 用 `new Date(a.createdAt * 1000).toLocaleString()`。
- **为何阻断**：① 直接命中 `docs/15 §15.4.1` 与 `docs/12`「禁裸 `new Date()`，一律 dayjs + Asia/Shanghai」的 🔴 铁律；② `toLocaleDateString('zh-CN')` 取**浏览器本地时区**而非北京时区，用户不在北京时区时展示时间与数据库（北京时间戳）差数小时。
- **修复**：两处统一改为 `import { formatBj } from '@competitor-crawler/shared'`，展示用 `formatBj(ts)`（秒级入参即 `dayjs.unix(ts).tz('Asia/Shanghai')`）。
